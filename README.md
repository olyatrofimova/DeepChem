# DeepChem
```
Split: random
  Train RMSE: 0.7566
  Test RMSE:  1.0906
Split: scaffold
  Train RMSE: 0.4531
  Test RMSE:  1.5365
```
Random split случайно делит молекулы, поэтому похожие структуры с общим каркасом попадают и в обучение, и в тест — модель «узнаёт» знакомые каркасы и показывает завышенную метрику. 
Scaffold split группирует молекулы по химическому каркасу и гарантирует, что тестовые каркасы не встречались в обучении, поэтому модель вынуждена обобщать на принципиально новые химические семейства. 
Это больше соответствует реальной задаче, где нужны молекулы с новыми каркасами, а не вариации известных. Поэтому scaffold split даёт более честную оценку, тогда как random split может создать иллюзию успеха.
